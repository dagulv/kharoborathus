## include

Exactly one css selector for the element holding the article body. null to abstain.

## exclude

Css selectors for boilerplate inside the include element.

## strip_after

Css selector of the first element after the article ends. It and everything after it inside include is removed.

## title

Css selector for the headline.

## published

Css selector for the publish time, prefer one with a datetime attribute.

## author

Css selector for the author name.

## image_policy

keep, or drop when images inside include are ads or promos.

## reasoning

One line explaining the rule.
